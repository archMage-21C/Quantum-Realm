# 📑 Research Papers

This folder contains **lists of research papers**. Each entry captures citation info, key results, and links to notes.

## Organization
- Papers grouped by field.
- Each entry includes:
  - Citation (authors, title, journal, year).
  - Link to Summary Notes.
  - Tags for quick search.

## Usage Notes
- Functions as a **curated bibliography** of important papers.
- Connects to notes and highlights.
- Helps track how ideas evolve across publications.
