# ✍️ Technical Drafts

This folder is used for **work-in-progress materials** related to projects.  
It is the **scratch space** where ideas evolve into structured documents.

---

## What to Store Here
- Early drafts of project documents.
- Technical write-ups, formulas, or design attempts.
- Notes that may later be cleaned and moved to **Project Archive**.

---

## Guidelines
- Organize drafts by project or theme.
- Use versioning in file names if necessary (`Draft_v1`, `Draft_v2`).
- Once a draft stabilizes, move or link it to the **Project Archive**.

---

## Purpose
- Encourages experimentation without worrying about “final form”.
- Keeps drafts separate from polished documentation.
- Supports iterative project development inside Obsidian.
