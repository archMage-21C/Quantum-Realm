# 🔧 Workbench

This folder is a **flexible space** for solved problems, exercises, experiments, or any miscellaneous work.  
It functions like a **personal lab notebook** inside Obsidian.


## What to Store Here
- Solved problem sets or derivations.
- Worked examples from books or papers.
- Small-scale experiments or coding snippets.
- Miscellaneous notes that don’t fit into Projects or Drafts.


## Guidelines
- Keep entries short and focused (one note = one solved problem/idea).
- Use descriptive titles: `Problem - Topic - Date`.
- Link related problems or notes for quick cross-referencing.


## Purpose
- A sandbox for **practice, exploration, and learning**.
- Provides a searchable repository of solved examples.
- May later inspire larger projects (to be archived in **Project Archive**).
